# 근무시간 (유연근무 트래커)

아이폰 Safari에서 쓰는 근무시간 기록·계획 웹앱입니다. 데이터는 아이폰 안(Safari 저장소)에만 저장됩니다.

## 계산 규칙
- 하루 순수 근무 8시간 / 월 기본 근로시간 = (평일 − 공휴일) × 8시간
- 출근: 도착 시각 **10분 단위 올림** (08:31 → 08:40) / 퇴근: 이탈 시각 **10분 단위 내림** (18:47 → 18:40)
- 휴게시간(법정): 4시간 근무 시 30분, 8시간 근무 시 1시간 → 8시간 인정에는 회사 9시간 체류 필요
- 연차 8시간 · 반차 4시간 · 반반차 2시간 인정
- 목표일 = 그 달 마지막 평일 (변경 가능)
  - 월·금 → **휴무** 목표: 전날까지 기본 근로시간을 다 채우도록 오버타임 추천
  - 화·수·목 → **조기퇴근** 목표(기본 15:30): 부족분만큼만 오버타임 추천
- 추천 오버타임은 하루 최대 1시간 30분(설정 가능), ‘약속’ 표시한 날은 제외, 앞쪽 날짜부터 배분

## 화면
- **오늘**: 출퇴근 시각, 근무 중 시간, 8시간 달성 시각, 추천 퇴근 시각, 지금 출근/퇴근 버튼
- **계획**: 월 요약, 목표 설정, 남은 근무일별 추천 출퇴근 스케줄, ‘약속’ 토글
- **기록**: 날짜별 기록 확인·직접 입력/수정, 연차·반차, 메모
- **설정**: 기본 출근시간, 최대 오버타임, 조기퇴근 시각, 공휴일·회사 휴일, 단축어 주소, 백업/복원(JSON), CSV 내보내기

## 아이폰 설정

### 1) 앱 열기 / 홈 화면에 추가
1. Safari에서 `https://<github-사용자명>.github.io/debbieandhoons-wedding/worktime/` 열기
2. 공유 버튼 → **홈 화면에 추가** → **‘웹 앱으로 열기’는 끄기**
   (단축어는 Safari로 주소를 열기 때문에, 앱도 Safari에서 열려야 같은 데이터를 봅니다)

### 2) 단축어 자동화 – 도착(출근)
1. **단축어** 앱 → **자동화** → **+** → **도착**
2. 위치: 회사 주소 검색 → 반경 조절 → **즉시 실행** 선택
3. 동작 추가:
   1. **현재 날짜**
   2. **날짜 포맷** → 날짜 형식 ‘사용자 설정’, 형식 `yyyy-MM-dd'T'HH:mm`
   3. **URL** → `https://…/worktime/?e=in&t=` 뒤에 ‘포맷된 날짜’ 변수 넣기
   4. **URL 열기**

### 3) 단축어 자동화 – 떠남(퇴근)
위와 같고 **떠남**을 선택하고, URL을 `?e=out&t=`로 바꿉니다.

> 정확한 주소는 앱의 **설정 → 단축어 자동 기록 주소**에서 복사할 수 있어요.

### 참고
- 점심 외출로 ‘떠남’이 찍혀도 다시 ‘도착’하면 퇴근 기록이 지워지고, 마지막 이탈 시각이 퇴근으로 남습니다.
- 자동 기록이 빠진 날은 앱에서 직접 입력하거나 ‘지금 출근/퇴근’ 버튼을 쓰세요.
- 처음 며칠은 기록된 시각이 맞는지 확인해주세요. 잠금 상태에서 URL 열기가 늦게 실행되면, 단축어에서
  ‘텍스트 파일에 추가’로 `in 2026-11-19T08:31` 형식 줄을 남겨두고 **설정 → 기록 텍스트 붙여넣기**로 가져올 수 있어요.
- Safari 데이터를 지우면 기록도 사라지니 **설정 → 백업 파일 저장**으로 가끔 ‘파일’ 앱에 백업하세요.
- 공휴일은 2025~2027년이 들어 있어요. 그 이후 연도나 회사 지정 휴일은 설정에서 추가하세요.
